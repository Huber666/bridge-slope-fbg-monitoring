# V2.4 室内小型失稳模型

日期：2026-10-14。当前阶段：有文献支撑的试制方案，尚未进行实体失稳、楼板承载或光栅适配验证。

推荐保留**1.00 m沿坡长度×0.50 m横坡宽度×0.12 m法向主动层厚度**；装入净空间1.40 m×0.50 m×0.85 m的室内土槽。基准坡角32°，可在制样前设置25°、30°、35°；采用实心砂/混合土主动层、薄低渗土床与刚性空腔支撑。不会把整个三角山体填满，也不把主动土层改为空壳。

相比V2.3，净箱体平面占地从0.96 m²减至0.70 m²，减少约27%；基准主动层土量从0.09 m³减至0.06 m³，减少约33%。两版有效坡长均为1 m，本版主要压缩箱体余量、宽度与主动层厚度。床身、平台、水和装置自重另外计入载荷。

论文证明小型土槽路线有依据，没有证明本方案已经是“最小可用模型”。先完成本版的机制、耦合与数据放行；若不通过，按清单返工，不以缩小尺寸优先。现场试验继续采用[V2.2模型与现场比较](../v2.2-manufacturing/边坡监测试验_模型与现场可行性比较.md)的组合路线，室内破坏数据须经真实现场非破坏性监测验证后再谈工程推广。
