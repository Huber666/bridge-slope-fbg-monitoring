## 本版成果

1. 病害与文献证据：分类、前兆、文献方法、量化结果的适用边界与首轮研究优先级。
2. 横向布纤与传感封装：测线坐标、方向盲区、直接埋设与位移转换节点、制造和现场安装节点。
3. 病害模拟模型制造方案：微位移台架、模块化土箱和条件性坡槽验证，材料、尺寸和装配步骤。
4. 实验与评价方案：标定、低幅值加载、土纤传力、对照、提前量、误报率及独立试验数据。

## 研究判据

不能从光栅标称分辨率推定土体检测能力。依次验证仪器与成品噪声、方向响应、土中传力、病害识别和提前量；与电阻应变片、独立位移仪及表面视频在相同条件下比较。负结果及不敏感方向应保留。

## 与 V3 的关系

V3保留为历史方案。V4不把V3的纵向点位、固定雨强和识别率目标作为定案；已有槽体、支架可在结构复核后用于后期坡槽试验。先完成微位移台架及土中耦合试验，再决定是否制造整槽。
