## 读者须知

手册中的 A0/A5/A10/A20/B30 配方、20/40/60 mm/h 雨强、500 至 1000 Hz 采样和 80% 喷淋均匀度等，是用于先导筛选的项目建议，不是论文给出的通用最优值。设计尺寸和方管、PC、板厚也不是结构验算或加工放行结论。正式试验前必须完成材料小试、完整底架与连接验算、限水检漏、无纤失稳试验、成品光纤湿态拉拔/温补标定和场地承载确认。

光栅信号不能单独当作滑坡标签。每个事件须有独立视频、位移、出水或其他真值证据；未失稳、泵噪声、工具扰动、同步失败和传感故障都要保留并标注，才能用于评估 CNN-LSTM 的误报和泛化。
