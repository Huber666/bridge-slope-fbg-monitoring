## 本版目标

## 合并与数值一致性检查

- V3统一采用V2.4/V2.5/V2.6现行基准：槽内净尺寸1400×500×850 mm、坡角32°、坡面床长1000 mm、平台100 mm、主动层法向120 mm、低渗床法向40 mm。
- 传感基准：s=125/375/625/875 mm，y=150/350 mm，n=40 mm；共8个应变测点和2个温度参考点，制造后需记录实测位置。
- 水量口径：土坡水平投影面积0.474024048 m²；20/40/60 mm/h计划土坡流量约9.480/18.961/28.441 L/h。喷淋接雨、裸槽面积、径流和渗流独立记账。
- 材料配比A0/A5/A10/A20/B30均为候选干质量比，不等同于论文验证配方；每层含水、干密度、渗透与强度需要本批次测试。
- 几何模型不称“1:20已验证相似模型”；当前为1g浅层失稳机制和传感数据采集试验台。
- V2.6的旧Word文档页数说明曾与实物不一致；V3重新生成DOCX并以最新渲染页数和逐页视觉核查为准。

## 试制前放行门槛

1. 结构：完成满载与水载荷、侧壁压力/挠度、框架侧向稳定、焊缝/螺栓、底架支承、地面承载和防倾覆核算并签审制造图。
2. 土体：完成级配、含水率、最小/最大干密度、目标密度、渗透、土水特征、低应力直剪及主动层/床界面剪切；筛选能重复初稳并出现目标机制的配方。
3. 水路：实测接雨空间分布、目标雨强误差、实际落土量、径流/床渗流计量和堵塞/溢流安全。
4. 光纤：厂家书面确认传感原理、标距、波段、点数、采样、带宽、弯曲半径、拉力和温补；完成全组件静态、湿态拉拔、弯曲/扫频和有纤/无纤对照。
5. 真值：相机标定、独立位移/振动参考、时钟同步与人工事件复核完成；预先冻结事件定义和按独立重建划分的数据集。
6. 场地：如开展真实现场验证，先完成场地风险、设备供电通信、安装许可、施工责任、数据授权、维护及退出方案；不为制造标签主动诱发现场破坏。
