# V3.0 边坡光栅监测模型综合方案

版本日期：2026-10-17。V3.0将V2.2至V2.6的文献、模型、制造、光纤布设、试验和三维构造资料整合到一个可执行版本，并补充逐篇文献综述、理论到实体映射和试制前闭环清单。旧版本目录保持不变，V3不覆盖历史快照。

## 使用顺序

1. 先读[文献综合评述与模型设计依据](文献综合评述与模型设计依据.md)，理解各论文证据等级、理论模型与实体参数的映射、尺度和边界限制。
2. 用[模型制造与装配手册](模型制造与装配手册.md)和[SolidWorks CAD文件](CAD)准备制造；[DOCX版手册](模型制造与装配手册.docx)适合打印执行。
3. 用[边坡监测试验操作手册](边坡监测试验操作手册.md)组织布纤、喷淋、真值观测和数据记录；[DOCX版手册](边坡监测试验操作手册.docx)适合现场使用。
4. 按[V3成果闭环与自检清单](V3成果闭环与自检清单.md)完成结构、土料、水路、光纤、真值和场地放行。

## V3基准与性质

室内1g浅层降雨失稳机制模型：槽内净尺寸1400×500×850 mm，坡角32°，床面沿坡长1000 mm，平台100 mm；主动层120 mm法向厚、低渗床40 mm法向厚。FBG候选布点为两排×四点、两温度参考；土坡水平投影面积0.474024048 m²。材料配方、雨强、传感封装、评价线均有候选或待验证属性。该装置不是已验证的1:20相似模型，不代表桥梁荷载、地震、长期风化或现场预警性能。

V3不是结构加工放行包。实际制造前必须有签审加工图、结构/地面承载复核、PC侧壁和水路验算；正式数据前必须完成土料低应力水力/强度测试、成品FBG兼容与传力标定、无纤和有纤对照及独立真值校准。详细放行条件见闭环清单。
