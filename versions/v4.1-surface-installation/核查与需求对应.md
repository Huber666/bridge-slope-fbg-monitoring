核查日期：2026年11月12日。结果适用于本次发布的研究方案，不代表制造验收、试验完成或工程安全评定。

## 需求覆盖

| 用户要求 | 已落实位置 | 尚未解决的边界 |
|---|---|---|
| 高速公路、高铁、隧道边坡分别是什么类型 | 第1节按工程场景、土岩、挖填分类；隧道限定洞口边仰坡 | 未给各类实际占比；铁路完整条文待补 |
| 哪些需要重点关注且要有依据 | 第2节结合交通暴露、排水、支承变化、落物路径、硬质覆盖隐藏变形；对应S1/S2/S5/S12 | 没有具体场地地质和历史资料，不能给统一风险等级 |
| 裸土、植被、混凝土网格、土工格栅等影响 | 第3节8类覆盖/防护/加固形式；明确骨架与锚杆框架、格栅与格室区别 | 根系和筋材参数需实测 |
| 室内怎么模拟 | 第4、8、10节：5组表面/土内配置、可换病害模块、干态差动和降雨分开 | 尺寸、坡角和材料参数不具有已验证的原型相似关系 |
| 优化光纤布设 | 第5—7、9节：四条安装路线、横向主光路、贴点坐标、温度参考、孔内传力 | 谱峰分配、胶型号、厂家量程尚未冻结 |
| 优先贴附，必要时打孔 | 先贴完整构件或两端底座；浅孔固定与深部传感孔区分 | 现场施工须按实际支护与稳定参考段确定 |
| 体现微应变感知优势 | 第10—11节：独立参考、检出限、固定误报预算、温漂/脱耦对照 | 尚不能宣称FBG优于电阻片或获得预警提前量 |

- S5—S7：CEDD Geoguide 5、6、7官方原文，用于覆盖接触、加筋传力、钻孔灌浆和监测的技术解释；不作为内地强制规范。

- S9—S10：核查格栅贴附FBG论文正文；注意模型背景、受力肋方向及胶损伤。
- S11、S13：结合V4已核论文正文与记录使用，不把纵向分布式光纤结果等同横向FBG证据。

正式执行前仍需核查标准最新适用版本和修改单。检索结果未找到的内容没有补写成事实，来源全文未随仓库发布。
