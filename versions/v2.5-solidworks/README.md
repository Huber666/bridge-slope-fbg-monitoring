# V2.5 SolidWorks室内边坡模型

2026-10-14。在本机SolidWorks Premium 2025 SP3.0中通过自动化接口实际建立、保存及重新打开验证。沿用[V2.4的土坡机制与尺寸依据](../v2.4-indoor-compact/README.md)，细化固定32°支架。旧版文件保留。

本版是**可测量、可编辑的三维构造讨论模型**，尚未完成结构验算和加工放行。没有开展降雨、滑坡或应力仿真；几何检查通过不等于承载通过。

## 为什么这样改

坡脚承托板顶面距槽底仅32.8，板下放不进40方管。因此斜梁在s=900处结束，末端由低位板式托座支承；托座的承压板与斜面平行，下面用3块腹板传力到6厚底板。这是本项目的工程构造建议，并非论文原样结构。

坡肩第一根横撑移至s=25，使整个40宽截面留在斜段下面；若以s=0为中心，横撑部分会越过折角并侵入土床。左右斜梁也自s=5起，避免同类问题。全宽横撑支撑连续承托板；不在主动土层内放横杆或固定光纤的钢梁。

主方管和低位托座拟由加工方分别在夹具中组焊。连续304承托板通过隔离垫放在其上，后续采用可拆压紧/螺栓固定；本版未画连接孔、压板和螺栓，不能把模型中的接触面视为已设计完成的连接。土床侧缘密封与坡脚排水也须在加工图中补齐。

## 光栅画到什么程度

8个红色占位件，外形110×8×6，轴向沿坡；两行y=150、350，沿床面s=125、375、625、875，距土床顶面法向40。它们仅用于检查布设空间，不能作为厂家制造图。未建模温度参考、松套引线、弯曲半径、内部光纤/胶层、保护和槽外铠装；实际方案仍须依据[V2.4安装要求](../v2.4-indoor-compact/室内小型失稳模型设计与制造方案.md)及主机/厂家回复确定。

总装干涉检查报告8处光栅占位与主动土体重叠，每处体积5.28×10⁻⁶ m³，等于110×8×6占位体积，是埋入关系。土体未专门扣除这8个小体积；它们不是可忽略土纤扰动的证明。

## 校核结果与预算修正

3套原生装配重新打开成功，2/4/9个零件引用全部解析。9个零件全部实体的Check2返回0，特征错误列表为空。钢支架和支架＋承托板装配均无体积干涉；总装除8处上述埋入关系外，没有其他体积干涉。接触不计体积干涉；不包含加工公差或变形后的检查。

CAD压实土床体积0.02235836 m³，主动土体积0.06707507 m³，合计0.08943343 m³，包含100平台，与独立解析计算相符。

**CAD暴露了V2.4自重预算偏低的问题。**按Q235B 7850 kg/m³、304 7930 kg/m³、PC 1200 kg/m³、EPDM 1100 kg/m³作预算假设：

| 已画构件 | 估算质量/kg |
|---|---:|
| 主方管钢架 | 33.28 |
| 坡脚低位托座 | 2.83 |
| EPDM垫条 | 0.19 |
| 304承托板 | 13.07 |
| 304槽底 | 16.93 |
| 四面PC观察壁 | 31.27 |
| 小计 | 97.57 |

上述是按CAD体积计算的预算，非实测；尚缺外部底架、观察壁压框、侧向斜撑、紧固件、密封、接土盘、水路与附件。按土体统一湿/近饱和密度1500～1900 kg/m³，加最多35 kg非孔隙储水，已画部分运行预算约267～302 kg，再加未画附件。土中孔隙水已在土体密度中，不重复计入。

因此不再沿用V2.4中40～70 kg装置自重和200～280 kg运行总重预算，也不能把300 kg当本装置已满足的额定承载。下一步须按完整BOM更新运行质量、偏心与支脚反力，再验算框架、板跨、侧壁、连接和室内放置位置。不能为了降重在未经计算的情况下直接减薄PC或钢板。

## 生成与复核

[build_solidworks.py](build_solidworks.py)保留建模参数和原生特征生成过程；[verify_solidworks.py](verify_solidworks.py)复核保存后的文件。运行需要本机SolidWorks许可、模板和Python pywin32；不会关闭用户已有文档。正常生成脚本检测到现存总装会拒绝覆盖，应先指定新的输出目录。

本版新增成果是CAD几何、构造修正、质量预算和校验记录；原文献证据与常重力相似性限制沿用V2.4，未新增论文或宣称已得到可训练的真实失稳数据。
