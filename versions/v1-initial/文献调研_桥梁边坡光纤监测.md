# 桥梁边坡光纤监测文献调研

更新日期：2026-09-21

后续说明（2026-10-12）：本文件记录早期多技术选型讨论；项目现已选用光栅阵列，新增依据见[光栅阵列边坡监测补充文献调研](../v2.2-manufacturing/光栅阵列边坡监测_补充文献调研.md)。本文“最好”“最成熟”等表述不构成同工况性能排名；不同数据集的识别准确率不能直接横向比较，融合方案属于待验证设计建议。

## 1. 调研范围与结论

本调研聚焦桥台、桥头路堤及邻近边坡的异常滑动和振动监测，重点考察分布式光纤传感、实体边坡模型及 CNN-LSTM 等时空识别方法。

主要结论如下：

1. **高分辨率缩尺模型中，Rayleigh-OFDR/OBR 是静态或准静态滑移监测效果最好的方案。** Schenato 等在 5 m 长降雨边坡模型中以 10 mm 空间分辨率、7--12 s 采样间隔监测预设滑动面；光纤在约 110 min 出现持续应变增长，128 min 才出现肉眼裂缝，137 min 完全破坏，相当于分别提前约 18 min 和 27 min 给出异常征兆。
2. **长距离现场工程中，BOTDA、PPP-BOTDA 和 BOTDR 最成熟。** 它们的空间分辨率通常为分米至米级，但量程可达公里级，适合桥台边坡、道路边坡和大型滑坡长期监测。温度补偿、光缆与土体耦合及应变到位移的转换，是能否工程化的关键。
3. **动态振动监测中，DAS/φ-OTDR 最合适。** 它可进行长距离、高密度、高采样率监测；但它主要反映动态应变率，不能替代 BOTDA/OFDR 对缓慢蠕变和永久变形的测量。
4. **算法上，CNN-LSTM 是成熟基线，不是所有数据集上的绝对最优模型。** 在受控光纤入侵振动数据上，CNN-CBAM-LSTM 报告了 97.9% 的四分类准确率；WPD 加级联机器学习报告了 98%，CNN-LSTM-Transformer 在六类数据上报告约 92%。这些数据集、类别和划分方式不同，不能直接横向排名，更不能直接外推到滑坡预警。
5. **本项目综合最优方案是双通道融合：分布式应变 + DAS 振动 + 少量传统真值传感器。** 仅用 CNN-LSTM 处理振动容易漏掉低速滑移，仅用静态应变又难以区分车辆、冲击和破裂事件。

## 2. 当前主流监测方案

| 方案 | 主要观测量 | 典型空间/时间能力 | 主要优势 | 主要限制 | 适合本项目的角色 |
|---|---|---|---|---|---|
| FBG 阵列 | 局部应变、位移、倾角、温度 | 准分布式；高频、高精度 | 技术成熟、抗电磁干扰、关键点精度高 | 测点离散，难覆盖未知滑面 | 坡脚、坡肩、桥台连接处的校核点 |
| BOTDR | 分布式应变、温度 | 常见为米级；公里级量程 | 单端接入、适合既有边坡长距离监测 | 分辨率和采样速度相对较低 | 工程现场长期监测 |
| BOTDA/PPP-BOTDA | 分布式应变、温度 | 分米至米级；公里级量程 | 信噪比和精度优于常规 BOTDR，工程案例较多 | 通常需要双端接入；温度和耦合补偿必需 | 大范围边坡表面网格或沿坡向布设 |
| Rayleigh-OFDR/OBR | 高密度分布式应变、温度 | 毫米至厘米级；量程通常短于 Brillouin 系统 | 空间分辨率最高，特别适合缩尺模型和滑面演化研究 | 量程、成本和现场耐久性受限 | 实体模型首选 |
| DAS/φ-OTDR | 振动、动态应变率、声学事件 | 米级测量单元；可达 kHz 级采样和公里级量程 | 实时、长距离、可定位，适合事件识别 | 对慢变/静态位移不敏感；数据量和环境噪声大 | 车辆、冲击、开裂、快速滑移监测 |
| 光纤声发射/主动波导 | 颗粒重排、剪切与破裂活动 | 高频事件计数和能量 | 对临破阶段敏感，可低成本预警 | 难直接反演位移，受安装和阈值影响 | 作为滑面破裂辅助通道 |
| GNSS/InSAR/UAV/测斜管/孔压计 | 表面位移、深部位移、水文状态 | 离散或周期观测 | 物理意义清晰、便于验真 | 空间或时间连续性不足 | 光纤系统的真值与交叉验证 |

## 3. “效果最好”需要按任务分别判断

### 3.1 实体模型中的滑移萌生与定位

**首选：Rayleigh-OFDR + 粗糙护套应变光缆 + 温度补偿光纤。**

已公开的大尺度模型结果表明，该方案可提供厘米级应变场，并在坡面可见裂缝之前识别持续应变增长。其优势不是单点精度，而是能同时显示异常出现的位置、范围和传播过程。模型试验中应将一条光纤布置在预期滑面附近，另设坡面纵横网格，以避免算法只学会预设滑面的先验位置。

### 3.2 实际桥台或道路边坡的长期监测

**首选：温度补偿的 PPP-BOTDA/BOTDA；只有单端接入条件时选 BOTDR。**

白水河滑坡案例使用固定点锚固与直接埋设相结合的平行应变/温度补偿光纤，处理后的变化趋势与 GPS 和现场变形一致。BOTDR 光纤测斜管也与传统测斜管具有较好一致性，并可定位潜在滑面。工程上真正决定效果的是光缆结构、锚固间距、土-缆界面和温度补偿，不只是解调仪指标。

### 3.3 异常振动和快速事件识别

**首选：DAS/φ-OTDR + 时频图或空间-时间图 + 2D CNN/CRNN。**

CNN-LSTM 适合“局部波形特征 + 时间演化”的组合；加入注意力模块可提升受控数据上的分类表现。对于连续 DAS 数据，建议把检测与分类拆开：先进行异常窗口检测，再进行事件分类和位置回归。对真实工程数据，应优先报告宏平均 F1、误报率和事件级召回率，而不是只报告样本级 accuracy。

### 3.4 综合预警

**综合最优：BOTDA/OFDR 应变通道 + DAS 振动通道 + 孔压/含水率/位移真值。**

推荐使用双分支模型：

- 应变分支输入“位置 × 慢时间”的应变增量、应变率和累积应变图；
- 振动分支输入“位置 × 快时间”的波形或时频图；
- CNN 提取局部空间和频带特征，LSTM/TCN/Transformer 建模演化过程；
- 在融合层输出正常、环境振动、局部变形、缓慢滑移、快速滑移，以及异常位置和风险等级。

这类融合方案的系统效果最好，但公开文献中尚缺少可直接复用的“桥台边坡双通道公开数据集”，因此本项目的数据采集和标签设计本身会构成主要创新点。

## 5. 对 CNN-LSTM 结果的正确解读

公开论文中的 90%--99% 准确率多数来自受控的敲击、步行、挖掘或管线入侵数据，不等于真实边坡预警准确率。常见风险包括：

1. 将同一次试验切成相邻窗口后随机分配到训练集和测试集，造成严重数据泄漏；
2. 正常背景样本远多于滑移样本，accuracy 很高但滑移召回率低；
3. 训练和测试使用相同埋设条件、土体含水率和激励位置，跨场景泛化未经验证；
4. 把车辆振动、雨滴、施工扰动误识别为边坡破裂；
5. 只做事件分类，没有异常位置、滑移量或提前量评价。

本项目应按整次试验或整段日期划分训练集、验证集和测试集，并至少报告宏平均 F1、每类召回率、每小时误报次数、定位误差和相对最终破坏的预警提前量。

## 6. 推荐的项目方案

若研究重点是“实体模型 + 光纤埋设 + CNN-LSTM”，建议采用：

1. **静态通道：** Rayleigh-OFDR 应变光缆，沿坡向 3--4 条、横坡向 2--3 条，在预设滑面附近增加一层；设置独立松套光纤进行温度补偿。
2. **动态通道：** DAS/φ-OTDR 光缆，优先布置于坡脚、桥台-填土连接区、潜在裂缝区，并与应变光缆保持可对应的空间坐标。
3. **真值通道：** 孔压、含水率、LVDT/拉线位移、加速度计和视频；没有这些真值，神经网络标签难以可信。
4. **试验工况：** 正常环境、车辆等效振动、冲击、分级降雨、坡顶加载、坡脚削弱、缓慢剪切和快速失稳；每种工况应在不同含水率和不同激励位置下重复。
5. **算法基线：** 手工特征 + SVM、1D-CNN、CNN-LSTM、CNN-CBAM-LSTM；数据足够后再比较 TCN 或 Transformer。先建立可信基线，再追求更复杂模型。

若经费只能支持一台解调仪：缩尺模型优先 OFDR；实际长距离边坡优先 PPP-BOTDA/BOTDA；若论文创新点明确要求“振动事件识别”，则优先 DAS/φ-OTDR，但需另加低成本位移或应变传感器弥补慢变盲区。

## 7. 检索说明

本轮通过 Crossref、OpenAlex 和 Europe PMC 等开放学术索引检索并核对论文标题、DOI、摘要、发表信息和引用情况。关键词包括：`distributed optical fiber slope monitoring`、`landslide BOTDA/BOTDR`、`Rayleigh OFDR slope model`、`distributed acoustic sensing landslide vibration`、`CNN LSTM fiber vibration recognition`、`bridge abutment slope fiber optic`。
