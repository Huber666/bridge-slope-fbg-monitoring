# 失稳模型材料、结构与制造方案

版本：V2.3；日期：2026-10-13；状态：材料小试与模型试制方案，非已验证的土料配方或承载加工图。

## 1 本阶段要造什么

建议造**可拆换、实心分层填土的土槽模型**，材料以有级配记录的砂和标准化细料为主；分别用“降雨入渗”和“坡脚分级削弱”产生浅层滑移与局部塌落。先在小土槽上把失稳条件做出来并验证训练标签，再放大到V2.2的箱体。不以外形像一座山、容易捏造或能手推滑动作为造模成功标准。

普通语言中的“滑坡、塌方”要先按试验现象区分：滑坡类关注沿界面或内部剪切带的滑移；局部塌落类关注坡脚失去支撑后局部块体/土团掉落和坡面后退。泥沙随水冲走属于侵蚀/冲刷，松散砂粒零星滚落属于表面颗粒运动，不自动都标为滑坡。若要研究岩块崩塌，须另设节理块体模型，不把砂坡塌落直接代表岩质崩塌。

核心验收：①初始能保持稳定；②在规定触发下出现可核实破坏；③重复制样后有相近但不被机械强制规定的破坏模式；④有位移/视频/水力真值；⑤光栅在关心的阶段仍有效且不明显加固坡体。五项缺一，先返工模型/安装，不进入大规模算法训练。

## 2 材料怎么选

| 候选材料 | 能支持的机制及依据 | 本阶段定位 |
|---|---|---|
| 洗净细砂/中细砂 | 摩擦性颗粒土；密度、层厚和渗透性可控制；多篇降雨水槽实验用砂或砂混细料[R1–R4] | **主选之一**：浅层入渗滑移、松散土滑动，需记录级配和相对密度 |
| 砂＋粉土/标准高岭土等细料 | 调整成坡性、渗透、吸力和剪切强度；砂混黄土实验表明细料会改变运动方式[R2] | **主选之一**：局部塌落/混合土坡；具体高岭土比例是本项目待验证配方，不是直接照抄论文 |
| 原状/重塑现场土 | 更贴近目标边坡，但空间差异、块石、运输和含水历史影响重复性 | 现场类型明确后作外部验证；先筛选同批原料，不能用随意挖来的“泥巴”替代参数控制 |
| 纯黏土或直接和成泥浆 | 可以研究软化、塑性与蠕变，但可能只沉陷/流动、不产生目标剪切模式；干缩和水力慢响应需控制 | 首轮不优先；作为低渗底层候选时也须测剪切与渗透，不能按手感定配方 |
| 砂砾/土石混合料 | 可研究块石接触和非均匀破坏，但传感压伤、颗粒尺度和重复性更难控制[R6] | 第二阶段：首轮用细料跑通，再扩大粒径并重新做土缆耦合和大尺寸剪切试验 |
| 太空砂/动力沙等商品玩具材料 | 商品配方、黏结剂和水响应通常依产品而异；本轮未找到足以支持本项目雨致滑坡相似性的直接证据 | 不作为主研究材料；可用于装配演示，但其数据单独命名，不混入真实土坡训练集 |
| 橡皮泥 | 常为不透水或低透水的黏塑性配方，靠塑性/时间效应变形；本轮未取得可移植的滑坡材料参数 | 仅用作形状、夹具或传感器传力演示，不能在未验证前用于雨致土坡主模型 |
| 泡沫/打印空壳/空心山体 | 缺少目标土体自重应力、渗流和内部剪切机制 | 做外观与布线演示；不作为坡体失稳训练数据来源 |

“不主选”不是断言替代材料不能做任何岩土模型。若将来使用，须明确其模拟对象，并实测摩擦/黏聚、刚度、密度、渗透和时间效应，证明能重现目标机制。对当前土坡入渗问题，工程土料证据更直接。

### 2.1 三组首轮材料，不同时改变所有变量

材料按**干质量**配制，选同批砂和同一来源細料：

- M0：100%砂，用于浅层滑移基准；测最大/最小干密度，按相对密度Dr控制，不把砂的Dr和黏性土压实系数K混为一项。
- M1：砂:细料=90:10，先检查成坡、干湿强度和入渗。
- M2：砂:细料=80:20，与M1采用相同目标干密度控制方法及水分制样记录。

这些比例仅是低成本筛选起点；没有文献证明它们在本项目坡角上必然滑动或塌落。对纯砂先测Dr=约35%/50%两个状态的可实现性，这是参考R4已有密度因素进行的本项目候选值；不能直接沿用R4的56.5°坡角、34%/48%密度就认为试验相同。M1/M2采用击实与实际制样密度标定，必要时改配比。

细料优先选成分及批次可追踪的粉土或高岭土；它们不是同一种材料。首轮只选一种做M1/M2，记录塑限/液限与粒径。若换细料，作为新系列，重新测定参数。

粒径首轮可先控制至≤2 mm，目标为薄层均匀制样和减少压伤，属项目建议；最终按筛分结果定义，不按“砂袋名称”认定级配。块石材料另设系列，不通过剔除块石后宣称还代表原来的土石坡。[R6]

### 2.2 决定配方前必须测什么

测定级配、颗粒密度、干/湿密度、含水率w、孔隙比e；含细料者补塑性指标和击实曲线。对选定密度和含水状态测直剪峰值/残余强度、界面剪切及渗透系数k。降雨主试验至少配含水率和孔压/吸力监测；资源允许时测土水特征曲线。

低模型自重应力下的材料尤其需要匹配试验应力水平：薄层模型法向应力可能仅几kPa，不能只用高法向应力拟合的c、φ外推。直剪设备达不到目标低应力时，补低荷载倾斜界面试验/较厚土层试验并说明限制。直剪试件排水、剪切速率和应力路径分别记录；非饱和“表观黏聚力”不能无条件当常数。

## 3 实心还是空心：把坡体和支撑分开

**发生破坏的土层必须实心填筑，禁止用空壳替代。** 箱体钢框架可以是空心方管；不参与变形的床身可以是下部空腔支架＋连续承托板，以节省土量，但必须证明刚度、密封、粗糙度和支承边界。

| 结构层级 | 推荐构造 | 能研究/不能研究 |
|---|---|---|
| 装置支撑 | 独立钢架、连续底板、透明侧壁、集水 | 维持边界和观测；本身不得松动后被当坡体信号 |
| 稳定床身 | 刚性承托板上铺压实砂质黏土或其他经验证的低渗透土层 | 控制水力和力学界面；须监测床身是否也变形 |
| 主动失稳层 | 实心松散砂或砂细料混合土，逐层称量制样 | 重现上层入渗、剪切、滑移/塌落 |
| 观察/传感 | 轻量视频标记、少量FBG和独立真值 | 记录破坏；不能用贯穿全坡的强夹具把本来会滑的坡锁住 |

R1直接提供“低渗压实砂质黏土床＋松散细砂上层”的现实实验依据。空腔支架是本项目节省材料的制造选择，**不是R1原装置**；若观察到床身挠曲或界面水从接缝旁路，需修正后重做。研究深层圆弧滑动、整体滑移或底层共同变形时，刚性床身不适合，必须改成足够厚的实心土体并重新设计边界。

不要把主动层装在可抽出的托盘里后拉动整个托盘来充当自然滑坡；那只得到机构运动和板摩擦信号。

## 4 先造小土槽，再决定大模型

### 4.1 首轮建议尺寸与工程量

不先固定原型比例，定义为常重力机制试验土槽。建议外部钢承力框架内可用净空间：顺坡水平长1.6 m、横坡宽0.6 m、最高侧壁1.05 m。设置可更换床身，在25°、30°、35°中选角度；选定后每次实验中固定，不边降雨边改变倾角。

坡床**沿面长1.0 m**；坡脚处床身上表面距箱底约120 mm，为50–100 mm低渗层及底板留下空间；上部失稳层沿面法向厚度先取0.10/0.15/0.20 m。顶端小平台水平长约0.15 m，坡脚留约0.4 m收集区，内部长度校核按实际断面出图。不要把“沿面厚度”与“竖直厚度”混用。

几何包络估算：35°时床身高差1.0sin35°≈0.574 m；法向厚0.20 m的竖向分量约0.164 m，若按竖直线与上表面交点计算则增高约0.244 m；按更保守竖直截面估算，0.12+0.574+0.244≈0.938 m，小于1.05 m。25°时顺坡水平包络约1.0cos25°+0.20sin25°+0.15+0.4≈1.54 m，小于1.6 m。实际平台和端挡几何须加工方复核，余高不足先降厚度/坡角或提高侧壁。

均匀主动层土量约1.0×0.6×0.15=0.09 m³，按湿密度1.5–1.8 t/m³预算约135–162 kg；0.10–0.20 m厚对应约90–216 kg。以上不含床身土、顶端平台、箱体和水，不能据此确定承载能力。试验需有坡脚收集防护和溢流排水；不要求人为快速失稳时人员手工近距离抽支撑。

小槽宽度仍存在侧壁效应。标记中心与近壁区域的运动，对比破坏起始；中心区也不能自动消除侧壁影响。横向扩展不一致或材料试验无法解释时，再用更宽的V2.2模型验证，不直接把小槽当现场相似模型。

### 4.2 模块A：降雨入渗浅层滑移，首要试验

床身先用经压实、低渗透且表面有实测摩擦的砂质黏土，主动层先用M0细砂。床身厚度候选50–100 mm，刚性底板承托；通过渗透和界面剪切测试选定，不使用涂润滑油/硬塑料滑面代替真实土界面。

定坡角、层厚、密度和初始含水状态后，静置建立无雨基线，再施加已校准的均匀降雨。先以20/40/60 mm/h为喷淋设备校准档，实际雨强根据k、土水特征、流失和积水小试选；不保证60 mm/h一定失稳，也不把R1的160 mm/h复制成统一雨强。箱内投影面积与喷淋覆盖面积分别记录，称入/出水并观察渗漏。

目标过程为：湿润锋下移→低渗层上方水分累积/孔压或吸力变化→变形发展→可见剪切/滑移。全程无位移而只有喷头敲击信号，应标为“降雨未失稳”；只发生表面冲刷应标侵蚀。始终不失稳，先检查水路/材料/边界再单独改角度、密度或厚度，不同时叠加拉绳和抬板强迫滑动。

坡脚排水与挡土是核心边界：采用可调、可观察排水口并记录挡板对土层的约束。挡板阻挡滑移会改变机制，固定挡板不可被省略在报告之外；在主试验中不突然撤除它再称纯降雨触发。

### 4.3 模块B：坡脚分级削弱产生局部塌落

采用M1/M2的实心混合土坡，先验证能保持规定初始坡形。与模块A分开重建，不在同一被雨水扰动后的坡体上进行“独立重复”。

在坡脚设置侧向可操作、可定深的局部取土工具或可移除端挡，按规定步骤减少支撑；首轮可试10–20 mm进深档位，具体由小试确定。工具退离后观察持稳、裂缝、土团脱落和坡面后退；工具自身运动段另标“施工扰动”。从中心或规定局部区域开始，保留边界范围，不能一次抽掉全底板。

此模块模拟开挖/冲刷导致的失去支撑，不代表未扰动自然降雨坡体。塌落体积、轮廓变化和事件时刻由视频/体积估计确认；若最终表现为完整块体沿剪切面滑动，按实际形态标滑移，不按预期强制标塌落。

### 4.4 模块C：正常背景与人工运动对照

在稳定土槽上重复正常降雨、局部轻敲、设备启停、模拟车辆振动、传感器松动和无永久位移的湿润沉降。用同一设备、采样与环境得到负样本，避免网络把“开喷头”直接当危险。

丝杆驱动的已知微位移模块可用于量程、响应和定位标定，数据单独标“人工位移”；不作为自然失稳正样本主体。岩块崩塌如后续需要，另造可定义节理/接触与重心的块体体系，补查岩质模型材料及断裂相似研究，不用本土槽结论代替。

## 5 光栅布设服从破坏机制

初期不强制沿用32点或防护网全覆盖。优先布置2条顺坡观测线，在坡肩、坡中、坡脚及目标界面附近设点，并配置隔离温度参考；实际点数由主机最小可分辨距离和样件外形确定。0.25 m点距能否分辨先测试；若主机相位标距数米，不能塞进小槽后宣称测到了局部剪切，先借用/适配短标距设备或扩大测段。

土内组件位于预计剪切带附近时，不用贯穿主动层的粗钢杆承载而形成隐蔽抗滑桩；拉拔锚片面积、光缆刚度与安装端点记录。比较有/无传感器的失稳位置和行为，检查传感器是否改变破坏模式。引线跨活动边界留服务余量，余量不得在有效感测标距内；跨缝用有量程的位移组件。位移达到量程后仍可继续记录视频，但光栅失真/断纤区间标无效。

首轮不同时铺刚性框架梁和高刚度格栅，它们会加固坡体，可能抑制要采集的失稳。加固结构作为后续对照变量，以相同土料、边界和触发比较；未加固与已加固数据分别记录。

## 6 怎么把试验做成训练数据

先做3组材料筛选，再选1–2组正式制样。预试验用于找稳定—失稳窗口，不纳入最终性能测试。正式起步建议：4类试验系列（降雨滑移、坡脚削弱、降雨不失稳、振动/施工干扰）×每类至少3个独立重建＝至少12次独立实验，作为流程与重复性验证；**不是足够训练CNN-LSTM的样本规模保证**。

成熟后再选2种材料状态×2种初始密度/水分状态×2种触发档×3独立重建＝每个目标失稳机制24次，另采匹配负样本。先只改变一个主变量；任一档不产生目标事件也保留，不删掉“失败的危险试验”。保持位移/视频足够帧率及原始光学数据，统一时间戳，记录触发命令与实际事件时刻。

标签分两张表：

| 标签维度 | 推荐定义 | 真值来源 |
|---|---|---|
| 实际事件类型 | 无失稳、滑移、局部塌落、侵蚀、外部振动/施工扰动、传感故障 | 独立视频、位移、坡形变化；按实际结果标注 |
| 变形阶段 | 稳定、可确认变形发展、快速运动、运动后 | 位移/速度及形态变化，不只凭FBG异常 |
| 触发原因 | 降雨、坡脚开挖、加载、人工位移、组合 | 试验记录，不能与事件类型混用 |
| 有效性 | 高置信、边界模糊、真值缺失、传感脱耦/超量程 | 交叉核查与信号质量 |

“失稳前”是回看最终事件的时间区段，并不保证每段都可检测前兆；不得将滑坡前任意长度窗口强制标为可识别危险。起动时刻不确定给时间区间，不造精确毫秒真值。模型按整次重建划分训练/验证/测试，不能把同一实验的相邻窗口分到不同集合；预处理只用训练集拟合。

初期输出事件识别、定位及位移阶段关系；安全系数估计是另一个需力学参数的任务，不把分类概率当安全系数。精度报告至少包含事件召回、宏F1、每小时误报、定位误差、检测延迟及未见材料/水分条件表现。

## 7 制造流程及进入正式数据采集的关口

材料采购与试验→小型无传感器成坡/入渗试验→确认基线和触发窗口→土槽结构与水路加工→安装独立真值→装少量已标定光栅→有/无传感器对照→至少3次独立重建复现→冻结制样与标签协议→扩展工况。

制造记录至少包括：材料批号、级配、干质量、加水量、实测含水率和密度、层厚/坡角、床身与侧壁处理、排水方式、光缆/锚片位置、喷淋均匀性、触发步骤及光学基线。拆坡后拍剪切带与层间结构；再制样前清理并检查底部渗漏/粗糙度，避免残留土导致每次不同边界。

三个停止放大条件：①没有明确失稳机制；②真值不足导致无法区分冲刷与滑动；③传感器显著改变边坡稳定性。出现任一项先返工材料、边界或布设，不先扩充神经网络。

## 8 文献与评价依据
