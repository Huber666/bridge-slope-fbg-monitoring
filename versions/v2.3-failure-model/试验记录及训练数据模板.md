# 试验记录及训练数据模板

日期：2026-10-13；适用V2.3失稳造模。一个独立重建坡体对应一个trial_id；时间窗口不是独立试验。

## 1 制样与工况卡（每次重建填写）

| 字段 | 填写内容 |
|---|---|
| trial_id / batch_id / 日期 | 独立坡体编号、材料批次、开始时间与时区 |
| 材料M0/M1/M2或新配方 | 砂/细料来源、干质量比、级配、是否回收土及回收处理 |
| 材料参数版本 | ρd、w、Dr或K、c′/φ′、界面强度、k、吸力/SWCC；标明已测/未测 |
| 几何 | 坡角、床身、主动层厚度（法向/竖直注明）、平台、侧壁与坡脚边界 |
| 填筑 | 各层干/湿质量、加水量、实测密度/含水率、厚度、工具与遍数 |
| 传感与真值 | 点号、坐标、轴向、标距、温补、安装件、原始单位、同步方式、校准版本 |
| 初始稳定性 | 无触发观察区间、参考位移/孔压/水分基线、是否自行掉落 |
| 触发 | 雨强与覆盖面积/流量、触发起止；或坡脚取土每步位置/进深；不得只写“强雨” |
| 排水/水量 | 入水、出水、径流、渗漏、溢流及床身界面水位观察 |
| 实际结果 | 无失稳/滑移/局部塌落/侵蚀/混合；首动位置、剪切带、运动范围及滑程 |
| 异常记录 | 工具接触、碰线、松夹、超量程、断纤、床身变形、侧壁先滑 |
| 拆坡记录 | 剪切断面与层间照片、细粒迁移、土层质量/回收处理 |

数据建议结构：每个trial_id下包含metadata、optical_raw、reference、video、events和photos。原始量与温补/滤波结果分开保存，照片/录像关联明确时间；中途更换传感器产生新标定版本。

## 2 事件表（同一试验可有多事件）

| event_id | trial_id | 起止时刻或区间 | actual_event | phase | trigger | 位置/范围 | 真值证据 | confidence | optical_validity |
|---|---|---|---|---|---|---|---|---|---|
| 待填 | 待填 | 统一时钟 | 无失稳/滑移/局部塌落/侵蚀/振动/施工扰动/故障 | 稳定/发展/快速运动/运动后 | 降雨/开挖/加载/人工位移 | 坐标与可见区 | 视频帧、位移、轮廓或孔压 | 高/模糊/缺真值 | 有效/脱耦/超量程/缺测 |

没有独立滑移证据的FBG峰变标为“传感异常待核实”；不强行贴正样本。工具/喷头开启时间和土体真正开始运动的时间分开；未能确认前兆的试验不填虚构提前量。

## 3 数据集划分与报告

按完整trial_id以及材料批次分配训练/验证/测试，至少留出一种未见水分/密度状态作为泛化检查。先划分再归一化、切窗或增强；同一坡体的相邻窗口不得跨集合。故障片段保留，但是否进入模型由任务定义决定，不能用正常零值填补缺测。

报告每类**独立事件数与独立重建数**，另报窗口数；失稳/不失稳全部保留。先比较简单阈值/特征法，再比较CNN-LSTM。报告宏F1、事件召回、每小时误报、定位误差和延迟；小样本不得用高窗口准确率掩盖独立事件不足。

## 4 造模自查

- 材料是否有可追溯配方和低应力参数？
- 主动层是否实心，床身/空腔支撑是否改变了水力和力学边界？
- 能否独立确认是滑移、局部塌落还是冲刷？
- 重建后是否复现同类机制，失败试验是否保存？
- 光纤与夹具是否显著加固土坡，运动后是否仍耦合？
- 是否有同条件不失稳、降雨和施工干扰负样本？
- 数据是否能按完整试验隔离，且标签不由光纤自证？

本轮完成文档设计，不代表上述检查已通过实测。未通过项回到材料或制造小试，暂缓正式训练。
