# 边坡监测试验模型与现场可行性比较

日期：2026-10-12

## 1 当前结论

推荐先开展传力标定和可控实体模型，同时调查真实边坡资源，再进入现场30–50 m短段监测。模型用于产生可重复、有位移真值的异常数据；现场用于验证背景干扰、长期耦合和工程部署。两者承担不同验证任务。

目前只有400 m×10 m国道边坡的方案描述，没有具体路段、业主联系人、地质资料或现场踏勘结果。不能据此认为场地已经落实，本报告属于资料层面的可行性与调查方案。

## 2 三种试验路径比较

| 比较项 | 自建室内边坡模型 | 校内或试验基地可控边坡 | 运营道路真实边坡 |
|---|---|---|---|
| 工况控制 | 高，可改变加载、降雨和滑面 | 较高，取决于基地装置 | 低，通常只能观察自然过程 |
| 异常标签 | 可通过位移和视频直接建立 | 可建立，需同步仪器 | 稀缺，需要长期观测和独立核查 |
| 重复试验 | 可重建，但耗费土体与人工 | 有条件重复 | 同一场地难重复失稳 |
| 现场真实性 | 尺度和边界有限 | 接近现场 | 最强 |
| 基建投入 | 箱体、加载、降雨和排水 | 可复用装置时较低 | 接入与维护成本可能较高 |
| 主要资源依赖 | 场地承载、土料、设备 | 基地合作与排期 | 业主、养护、监理及现场作业条件 |
| 最适合任务 | 传力、定位、算法有标签数据 | 近现场验证与规模放大 | 耐久、误报、通信和部署验证 |
| 当前落实状态 | 已有建议设计，尚未制作 | 尚无已确认资源 | 尚无已确认具体路段 |

是否节省费用取决于现有设施和设备，不按“现场不造模型所以一定更便宜”判断。实际预算至少包括传感器、解调仪、接续保护、施工、维护、真值设备、供电通信和多次试验人工。

### 3.2 一轮调查应输出什么

先从两个真实研究区和一个可落实的本地工程段各建立一张记录卡。要求管理方书面明确可安装区域、构件材质、固定限制、已有真值及数据可共享范围；项目自行记录供电、通信、通行与维修路径。若某候选缺少管理许可，不进入施工设计；若没有共享位移数据，预算中新增真值设备。

第一轮结论应为“可安排踏勘/需另找管理方/仅能提供资料/不可用”，而非只给一个未经调研支持的综合分数。现场调查与设备小试同步；当前已完成公开资料筛查，尚未完成实地踏勘和资源落实。

### 3.3 其他可拓展资源类型

1. 校内岩土实验室或合作单位试验基地：询问是否有降雨边坡槽、加载框架、振动台、室外可控填土坡及剩余排期。
2. 当地公路养护或桥梁运维单位：优先选择已有格栅/框架防护、资料齐全、便于到达的稳定路段；查找正在建设或维修且允许预埋的试验段。
3. 边坡加固施工或设计单位：确认是否有可共享的框架梁、土工格栅、试验样件及已知施工监测需求。
4. 光栅阵列设备供应方：确认是否有已运行示范站、可提供短栅距样段及原始数据接口。

文献中出现的香港鹿颈、温州等场地，只证明FBG已有工程应用路径，不代表这些场地现仍开放试验。本阶段未代替用户联系任何单位，也未取得场地使用承诺。

## 4 场地调查记录表

| 调查内容 | 需要得到的事实 | 对方案的影响 |
|---|---|---|
| 位置和权属 | 具体路段、养护/业主、可用区域 | 决定能否安装和维护 |
| 地质与历史 | 土岩类型、层面、地下水、滑坡记录 | 决定测线与真值位置 |
| 防护结构 | 土工格栅、防护网或框架梁，节点和锚固 | 决定传力及安装工艺 |
| 坡形与尺度 | 坡高、坡角、台阶、可用测线长度 | 决定两排或多排观测 |
| 已有监测 | GNSS、测斜、雨量、孔压、巡检记录 | 决定标签可信程度 |
| 安装条件 | 可否粘结、夹持、开槽或钻孔 | 决定传感封装和施工费用 |
| 运维条件 | 电源、太阳能条件、通信实测、设备箱位置 | 决定持续采集能力 |
| 数据条件 | 获取权限、协议、时间戳、可保留原始量 | 决定训练与复现 |
| 试验边界 | 允许的非破坏性测试、作业时间 | 决定现场能验证哪些任务 |
| 对照条件 | 独立位移、视频和温度设备 | 防止把光纤异常自证为滑移 |

候选场地只有在权属、安装方式、独立真值和连续供电通信四项明确后，才进入施工设计。无需等待发生滑坡才验证系统，可先完成正常背景与已知非破坏性事件测试。

## 5 现场短段建议

建议长度30–50 m，优先覆盖一段已知防护构件和明确的上下测线。若设备感测单元约5 m，两排各约6–10个单元，合计约12–20个区段；具体端点和光栅数由供应方图纸确认。

安装位置以坡面构件为主，温度参考点、独立位移点及加速度参考点同时配置。已有地下变形仪器可作补充；没有深部真值时，不宣称已监测完整滑面。

首期建议连续采集不少于30天，覆盖昼夜温度与日常交通；这是试点观察窗口，不是足以验证所有季节或捕捉失稳的保证。降雨不足时延长观测。开始前保存安装与零点基线，记录日常交通、维护及天气事件。

现场只开展许可范围内的轻敲、局部微位移标定和正常环境观测；人工诱发滑移、坡脚卸载及破坏性加载留在专用试验模型或受控基地。设备报警和交通处置由既有管理流程决定。

验收关注传感器在线率、有效数据率、温补零漂、事件误报、已知点定位、数据回传和故障恢复。5秒推送是可测试的系统延迟目标，不等于能在滑坡前5秒作出可靠预测。

### 5.1 施工和安装工作包

1. 踏勘后绘30–50 m沿坡段图，先明确坡高、防护材质、构件锚固和候选滑移方向。两排分别在约0.25H和0.75H；高程与路线用实测坐标，不把二维图上长度当购缆长度。
2. 在可检修构件上安装少量同材料试件，比较N1夹持或N2表贴；先测湿态抗滑和已知微变形，不在未经许可的框架梁切槽。
3. 点式FBG按关键构件节点和变形区布点，不能仅按5 m划格后承诺连续覆盖；超弱相位阵列按实际Lφ配置连续耦合路径，两排30–50 m对应约60–100 m有效线长，另加所有引线和预留。
4. 跨沟、路侧到机箱段均为L保护引线；跨可能移动接缝用位移组件与服务弯，不能靠松弛感测段接收滑移。温度参考按上下、阴阳面等热区划分，不机械照搬模型4点。
5. 箱外/稳定平台设机箱、接续与供电通信；验收入场、固定、保护、调试四个状态光谱及点表。真值与光栅同步，巡检记录天气、交通、施工和掉线。

### 5.2 现场能验证的结果

首期30天统计有效数据率、每点温补残差、非破坏事件定位、背景事件误报率、维修工时；慢滑移评价只有在独立位移确认发生变形后开展。没有异常时可以证明正常背景与运行能力，不能证明滑坡召回率或预警提前量。至少覆盖更长湿热/降雨过程才能评价耐久，季节结果与一个月试点结果分开报告。

建议并行保留模型数据和现场数据，CNN-LSTM先做模型独立批次测试，再用现场背景测试域差异；现场没有滑移真值时不把模型准确率标成现场准确率。

## 6 实施顺序与交付

| 阶段 | 主要工作 | 可交付结果 | 进入下一阶段的条件 |
|---|---|---|---|
| 一 | 设备资料核对与传力试件 | 阵列适配、连接标定、点位草图 | 能分辨目标异常区域且静态/动态输出明晰 |
| 二 | 局部实体模型及独立重复 | 工况数据、真值标签、算法比较 | 干扰与滑移可区分，误报和定位有量化结果 |
| 三 | 候选场地踏勘与短段方案 | 路段记录、安装设计、报价 | 业主条件、真值、供电通信落实 |
| 四 | 连续现场试点 | 实际背景、耐久、运维和误报报告 | 指标满足双方确认的验收目标 |

场地资源调查可与阶段一、二同步推进。工作日程依赖样件交付、实验室和合作单位排期，不把建议阶段写成已经完成的进度。

当前可直接开展的是设备资料整理、小试标定和候选场地调查表填报；大规模400 m铺设应在短段验证后决定。

## 7a 工作量与可报价的费用模型

现阶段没有供应商/施工报价，下面给数量和费用计算方式，不虚构市场成交价。共同设备单独计，比较方案时不重复购入可共享的解调仪和真值系统。

定义：C共用=解调与记录系统＋真值设备＋厂家样件及标定；C模型=箱体/门架＋降雨排水＋模型构件＋土料/重建人工＋实验场地；C现场=踏勘与手续协同＋现场传感线路＋安装作业＋供电通信＋机箱/接续＋往返和维护＋独立现场真值补缺。阶段组合费用=C共用+C模型+C现场，现场线路的额外通道/主机另算。

| 可询价项 | 自建模型数量依据 | 30–50 m现场数量依据 |
|---|---|---|
| 主体设施 | 净2.4×2.0×1.2 m箱体1套、独立门架1套 | 不造箱体；可能需工作平台、作业通行与临时设施，按踏勘 |
| 模型/工程材料 | 净土3.04 m³/重建；湿备料约5.0–6.0 t/批次 | 若仅表面夹持，不计整坡开挖土方；开槽另按批准长度断面计 |
| 光栅与安装件 | 30/32点；24应变对应48个端夹位置，位移另计锚座 | 连续弱阵列60–100 m有效线，或另编点式点表；两类不能混用报价单位 |
| 跳线与铠装引线 | 按8串分别量测路线＋余量 | 有效线长外另计往机箱线路、跨沟、引入与接续余量 |
| 重复试验人工 | 至少3独立重建批次，称量、填土、拆装、标定 | 安装及首期至少30天采集，多次巡检；异常稀缺不能买来重复次数 |
| 持续运行 | 实验室电源/计算机/值守 | 功率×24 h定日能耗，核算光伏/电池余量；通信流量按原始采样通道计算 |

把各项数量Qi与厂家含税单价Pi填入C=ΣQiPi＋运输/安装/检验/维护，注明设备购置、借用或租用。预留金可先按直接新增费用的10%–15%作为方案假设，报价后调整；不能将预留金当固定行业标准。

选择顺序：能借用同类坡槽且承载/排期可确认时，优先使用既有基地＋本项目夹具/阵列，少建箱体；没有现成设施则做小型传力试架再分步建模型。真实研究区可提供真值且安装许可明确时，现场试点最有价值；仅有自然边坡而无真值/维护条件时，不能取代可控模型。

## 7b 推荐与当前完成度

推荐“构件小试先行＋可控模型产标签＋具体现场短段验耐久”的组合。与完全自行搭建相比，复用研究基地可节省基础设施但受排期和边界限制；与仅上真实边坡相比，组合方案能获得可复现异常、避免等待自然失稳，并通过现场验证温度、交通和安装老化。

本报告已补具体候选地点、论文证据、安装任务和可报价工作量，完成资料层面的方案建议。**场地可用性仍待管理单位核实及踏勘**；没有虚写已达成合作，也没有代用户联系任何单位。
