# 桥梁边坡光栅阵列监测方案

本项目研究桥台及道路邻近边坡的异常滑动与振动感知，重点包括实体模型制造、FBG光栅阵列封装铠装与布设、独立真值试验及CNN-LSTM识别。文档按现存版本分目录保存。
